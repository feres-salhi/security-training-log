## 🗂️ Structure

Each phase has its own folder. Each solved lab or challenge gets a short write-up:

- **Goal:** what the challenge asked
- **Approach:** how I solved it, step by step
- **What I learned:** the concept behind it
- **Defense:** how to prevent this vulnerability in a real application

---

## ⚖️ Ethics

All work in this repository is done on legal training platforms built for practice.
I follow each platform's rules. Where a platform asks not to publish solutions (for example OverTheWire), I only document the concepts and commands I learned, never passwords or full solutions.
